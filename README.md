# Sunda Islam Corner

Frontend React + TypeScript + Vite.

## Menjalankan project
1. Install Node.js
2. Buka folder project di VS Code
3. Jalankan:
   npm install
   npm run dev
4. Buka URL yang muncul di terminal (biasanya http://localhost:5173)

## Edit katalog buku
Buka `src/App.tsx`, lalu ubah array `books`.

Setiap buku punya:
- title
- author
- university
- category
- cover
- link

Ganti `link` dengan URL katalog universitas tujuan.
